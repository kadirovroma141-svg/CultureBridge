💻 Example: Compare two cultures

curl -X POST {{ site_url }}/api/compare \
  -H "Content-Type: application/json" \
  -d '{"from":"KZ","to":"IT"}'

Returns CDI score, per-dimension gaps, culture-shock risk level, and an adaptation checklist.

💻 Example: AI Subtext Decoder

curl -X POST {{ site_url }}/api/subtext \
  -H "Content-Type: application/json" \
  -d '{"phrase":"Your idea won'\''t work","country":"JP"}'

Returns conflict risk (0–100), interpretation, face-threatening features, and polite rephrasings in English and Japanese.

⚠️ Error Responses

All errors return JSON with an error field:

{"error": "Validation failed", "details": [{"field": "country", "msg": "value is not a valid country code"}]}
400 Bad request — missing or malformed JSON body
404 Not found — country code or resource does not exist
422 Validation error — body does not match expected schema
429 Rate limited — too many requests
500 Internal error — logged server-side
